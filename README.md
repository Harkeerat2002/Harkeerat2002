- 🎓 **MSc Computer Science at [EPFL](https://www.epfl.ch)**, specialisation in Data Analytics (2024 – 2027) · BSc CS at USI Lugano, exchange at ETH Zürich
- 🤖 At **Cisco** (Wireless AIOps), I built and shipped an **LLM agent** that lets engineers query network KPI data in natural language instead of SQL
- 📈 Took it from near-zero to **>70% correct answers** and **>90% technical success**, with hybrid retrieval over a knowledge graph and an LLM-graded evaluation framework
